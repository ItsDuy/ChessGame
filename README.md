# ChessGame
Hi there is my take on the classical chess game in built Unity.
Hope you like it and can leave a feedback.
About the Project:
This is the fully functional local compete chess game display a resolution 16:9 built in Unity 2022.3.44 f1.
The game offers many game mode from Bullet,Blitz to Rapid.
Features:
8x8 tiles with 2 oppsoing chess pieces with their implemented moving and capturing rules: 8 Pawns, 2 Knights, 2 Bishops, 2 Rooks, 1 Queen and 1 King.
Additionally, the games is also includeded advanced rules like: Check, CheckMate, EnPassent, Promote and Ask_For_Draw or even Surrender.
Highlight Legal Moves: Visual indicators show valid moves for selected pieces.
Provide diverse gameplay options: Like the offical tournament chess people can compete on the wide range of chess modes: Bullet - Blitz - Rapid .
Highly customizeable Avatars: There are 8 avatars to choose for 2 players.
Installation Instructions:
- Download Unity: Ensure you have Unity version 2022.3.44f1 installed on your system. You can download it from the Unity Hub.
- Clone the Repository: Clone or download the project files from the repository.
git clone <repository-url>
-Open the Project: Launch Unity Hub.
Click on "Open Project" and navigate to the folder where the chess game files are located.
- Build and Run:
Open the Build Settings in Unity (File > Build Settings).
Select your target platform (e.g., PC, Mac, Linux, etc.).
Click "Build" to create an executable file, or click "Play" in the Unity Editor to test the game.
